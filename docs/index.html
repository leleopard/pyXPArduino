pyXPArduino v1.3

Python/PyQt5 application that bridges Arduino microcontrollers with X-Plane flight simulator. Configure physical cockpit hardware (switches, potentiometers, servos, rotary encoders, PWM) and map them to X-Plane datarefs and commands via USB serial + UDP.

Main Application

  • pyXPArduino Main window, UI orchestration, config and thread lifecycle management

Core Library Modules

  • lib.Arduino Thread Per-board controller — input routing, output refresh, interpolation
  • lib.arduinoXMLconfig XML configuration CRUD, observer callbacks, pin constants
  • lib.arduinoSerial Thread Low-level serial I/O, Arduino serial protocol, command queue
  • lib.XPrefData X-Plane dataref and command reference file loader and filter helpers
  • lib.serialArduinoUtils USB serial port discovery by Arduino serial number

Serial Protocol Reference

See lib.arduinoSerial module documentation for the full Arduino ↔ PC message format.

Known Defects

  • BUG-01 — ArduinoSerial.quit(): arduinoReady not reset on disconnect (== instead of =)
  • BUG-02 — arduinoConfig.updateComponentData(): malformed XPath causes IndexError
  • BUG-03 — Arduino.__refreshOutputs(): silent except: pass swallows serial failures
  • BUG-04 — Multiple bare except: clauses across modules suppress error context
